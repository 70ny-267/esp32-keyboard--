# AutoTyping 微信小程序蓝牙控制器

专为 ESP32-S3 智能硬件键盘开发的独立微信小程序，支持在苹果（iOS）与安卓（Android）微信中原生运行。

## 核心功能

1. **自动蓝牙配对**：点击“一键连接”自动扫描并安全握手 `AutoTyping-BLE` 硬件。
2. **剪贴板一键粘贴**：支持点击按钮直接从手机剪贴板读取并填充内容。
3. **4 档速度预设**：
   - **沉稳慢速** (~15 WPM，严格按照你真实测量的生物数据节奏)
   - **常用自然** (~30 WPM，适合日常中等速度)
   - **流畅熟练** (~45 WPM，偏快输入)
   - **极速爆发** (~65 WPM，极限敲击)
4. **生物特征开关**：
   - 模拟手误退格（1.5% 邻近键打错并退格修正）
   - 标点与换行思考停顿（300~900ms）
5. **实时双向控制**：
   - 随时在手机上点击【暂停打字】与【继续打字】（或配合板载 BOOT 键使用）
   - 【紧急中止】清空队列
   - 实时接收板子回传的进度与状态通知

## 如何在手机上打开并使用此小程序

无需注册企业开发者账号，普通个人微信即可直接预览使用：

### 第一步：下载并打开“微信开发者工具”
1. 前往微信官方网站下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（Mac 版）。
2. 打开软件，使用手机微信扫码登录。

### 第二步：导入本项目
1. 在开发者工具中点击 **“导入项目”**。
2. **目录**：选择本地路径 `/Users/mac/开发/自动键盘/miniprogram`。
3. **AppID**：点击下拉框选择 **“测试号”**（无需申请，系统自动生成）。
4. 点击 **“确定”** 进入。

### 第三步：在手机上运行（苹果 / 安卓均可）
1. 在微信开发者工具顶部，点击 **“预览”** 按钮。
2. 屏幕上会生成一个二维码，**用手机微信扫一扫该二维码**。
3. 你的手机微信里就会立刻打开并运行这个专属控制小程序！
4. （提示：在手机右上角 `···` 菜单里，点击“添加到我的小程序”或“添加到桌面”，以后随时一键点开使用）。
